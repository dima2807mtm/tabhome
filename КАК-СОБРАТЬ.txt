КАК ПОЛУЧИТЬ APK ВАШЕГО ЭКРАНА (бесплатно, через GitHub, без Android Studio)
=============================================================================

Делаем так же, как уже делали с Wink Home для ТВ.

1. На https://github.com -> New repository. Название любое (например tabhome),
   видимость Private -> Create repository.
2. На странице репозитория: "uploading an existing file" -> перетащите ВСЁ
   СОДЕРЖИМОЕ этой папки: settings.gradle, build.gradle, gradle.properties,
   папки app и .github (именно содержимое, а не саму папку launcher-project).
   Если папка .github не перетащилась (так уже было один раз) - Add file ->
   Create new file -> в имени впишите .github/workflows/build.yml -> вставьте
   содержимое файла build.yml из этой папки -> Commit changes.
3. Вкладка Actions -> если не пошло само, build-apk -> Run workflow.
   3-6 минут до зелёной галочки.
4. Открыть запуск -> Artifacts внизу -> скачать tabhome-apk (это zip).
5. Распаковать, получить tabhome.apk, положить в папку xiaomi-tablet-toolkit
   рядом со скриптами (где 01-connect.cmd и т.д.) -> запустить 05-install-launcher.cmd.

Что делает этот экран
  * Фон - фото природы (12 штук, меняются раз в 20 минут, интернет не нужен).
  * Слева вверху - приветствие, часы, дата.
  * По центру внизу - три иконки: Иви, Кинопоиск, Chrome (иконки настоящие,
    берутся из самих установленных приложений). Если приложение ещё не
    поставлено - покажет подсказку поставить его через HyperOS.
  * Справа вверху - кнопка-шестерёнка: при первом нажатии попросит задать
    4-значный PIN, при следующих - спросит PIN и, если верный, откроет
    расчищенный рабочий стол HyperOS (сам экран остаётся главным - после
    Home вы снова на нём).
  * Если нужно поменять набор приложений (добавить/убрать) - просто
    напишите мне, какие нужны, я поправлю список APPS в HomeActivity.java
    и пересоберём за те же 3-6 минут через Actions.
  * PIN хранится только на самом планшете (в памяти приложения). Если
    забудется - Настройки -> Приложения -> "Мой экран" -> Очистить данные
    сбросит PIN (попросит задать заново при следующем нажатии на шестерёнку).
